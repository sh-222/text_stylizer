# Text Stylizer Bot

Это Telegram-бот шутка, который позволяет пользователю изменять текст различными способами.Весь код включая написание промта в этом проекте написан ИИ-агентом  с использованием DeepSeek v3 и Lingma(qwen3),я лишь ввёл дополнително 54 уточняющие инструкции и ни строчки кода своими пальцами. Было весело :) Бот принимает текстовые сообщения и преобразует их в различные стили. Этот текст от начала и до конца, так же написан исскуственным интеллектом . И он же отправил сюда весь код и вообще всё:) 

## Функциональные возможности

- **Zalgo-текст**: Добавляет случайные диакритические знаки к тексту для создания "испорченного" эффекта
- **Разделённый текст**: Добавляет дополнительные пробелы между буквами
- **Верхний регистр**: Преобразует весь текст в верхний регистр
- **Fancy Font**: Преобразует буквы в стилизованные символы
- **Текст в изображение**: Создаёт изображение с текстом (используя шрифт DejaVuSans)
- **Очистить**: Сбрасывает текущий текст

## Технологии

- [Aiogram](https://github.com/aiogram/aiogram) - Асинхронная библиотека для работы с Telegram Bot API
- [Python Pillow](https://pillow.readthedocs.io/en/stable/) - Обработка изображений
- [python-dotenv](https://pypi.org/project/python-dotenv/) - Загрузка переменных окружения из файла .env

## Архитектура проекта

```
├── fonts/              # Шрифты для генерации изображений
├── handlers/           # Обработчики команд и callback-запросов
├── keyboards/          # Клавиатуры Telegram
├── utils/              # Вспомогательные функции для модификации текста
├── bot.py              # Основной файл запуска бота
├── requirements.txt    # Зависимости проекта
└── Dockerfile          # Файл для сборки Docker-образа
```

## Установка и запуск

1. Создайте файл `.env` с вашим токеном Telegram:
   ```
   BOT_TOKEN=ваш_токен
   ```

2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```


3. Запустите бота:
   ```bash
   python bot.py
   ```


## Использование

1. Отправьте команду `/start` боту
2. Отправьте текст для модификации (до 100 символов)
3. Выберите способ изменения текста из предложенных вариантов
4. Повторно выбирайте разные стили для преобразования текста
